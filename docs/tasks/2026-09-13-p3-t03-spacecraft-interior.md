# P3-T03：驾驶舱、生活舱与气闸内舱

## A. 规格

- 需求：用户在外部细化版展示后指示继续，进入既定内舱任务。
- 等级/路线：C2，Codex 主导 Blender 制作与资产验收；当前 GPT-6，沿用已确认的专业制作授权。
- 状态：`accepted`（2026-09-13 用户明确确认内舱布局）。
- 继承 P3-T01 双人单层、暖白/石墨/青色/琥珀色方向；与 P3-T02 原点、米制单位、+Y 船首/+Z 向上对齐，不缩放外船。
- 交付：驾驶舱双座、控制台、生活舱设备柜与折叠休息设施、装备缓冲区、后气闸；Blender 源文件、LOD0/1 GLB、剖面与舱内独立预览、尺寸/通道/节点/资产清单。
- 内舱预算：LOD0 100k–160k、LOD1 40k–80k 三角面；LOD2 不渲染内舱。
- 主通道净宽至少 1 m，净高至少 2.1 m；门洞至少 0.9 m；双座走道止于座椅后方，座椅间控制台不是贯通走道。

## B. 前置评审与边界

- 驾驶舱眼位与座位从已验收外部 Blender 锚点读取，不猜测变换；内舱另保留站立点、设备与门交互锚点。
- 单层地板贯通，尾部根据外壳收窄；只制作静态门框和内门独立节点，门运动/互锁是 P3-T04 与 P5 任务。
- 默认剖面预览隐藏上部围护；舱内视角显示围护。独立查看器只加载当前所需内舱，可切换 LOD；不修改产品 renderer。
- 允许：本任务文档、P3-T02 最终验收记录、路线图 Phase 3/下一任务状态、README 模型资产现状、内外资产登记状态；`assets-source/blender/scripts/` 相关新脚本及可复用导出校验脚本；`assets-source/blender/spacecraft/interior/`；`src/assets/models/spacecraft-interior-lod{0,1}.glb`；新增内舱资产清单。
- 禁止：外部已验收几何/GLB、飞行/碰撞/音频/航线/主 UI、依赖和构建配置、宇航员/动画/气闸状态机；无提交、推送、部署、安装依赖或外部资产。
- 验证：实际几何预算、有限坐标、单位与锚点、通道体积与外壳包络；glTF 解码验证；Three.js 两档加载与切换；类型检查、测试、构建；Blender/浏览器截图逐项查看。
- 风险：静态包围盒检查不等于角色胶囊运动；内舱与外部组合时需要后续可见性裁剪。以独立预览完成本次资产级检查，运行时整合另立任务。
