# P3-T07：座椅、舱门、控制台和锚点交互

## A. 规格

- 状态：`accepted`。
- 等级/路线：C1，Codex 独立完成。用户已明确要求后续代码不再交接 Grok；当前使用 GPT-6，并已授权继续复杂 3D 运行时工作。
- 目标：在 P3-T06 的正式 PBR LOD1 飞船上接入现有机械动画和交互锚点，使座椅、控制台、内舱门与外舱门在产品驾驶流程中可操作、可暂停、可复位和可释放。

### 用户可见行为

1. 飞船模型就绪后，驾驶面板显示当前交互锚点、座椅、控制台和两扇舱门状态。
2. 用户可选择驾驶座、站立点、控制台、内舱门、气闸、EVA 和安全绳锚点；点击交互按钮或在画布聚焦时按 `F` 执行当前锚点动作。
3. 驾驶座进入真实座椅视角；站立点离座并返回跟随视角。现阶段不生成宇航员，也不伪装舱内行走。
4. 控制台播放/停止 `ConsoleActive`；内外门使用 GLB 的开关动画，并保持机械互锁：一扇门未完全关闭时不能开启另一扇门。
5. EVA 与安全绳锚点只验证并显示为后续阶段保留，交互时给出明确提示，不启动 EVA。
6. 暂停、窗口失焦或页面隐藏时，门和控制台动画不推进；复位关闭舱门、关闭控制台、清除提示并恢复默认锚点。
7. 退出飞船预览后停止并释放 AnimationMixer；重复进入不创建第二个 renderer，不复用已销毁 mixer。

### 非目标

- 不实现宇航员、舱内行走、角色碰撞、坐下/起身角色动画、手部 IK 或控制权切换；这些属于 Phase 4。
- 不实现气压、减压、生命维持、头盔检查或完整气闸状态机；这些属于 Phase 5。
- 不修改 Blender、GLB、纹理、构建配置、依赖、持久化或音频系统。
- 不改变飞行、航线、近星体防撞、相机碰撞和 renderer 生命周期。

## B. Codex 前置评审

### 资产事实

- `spacecraft-pbr-lod1.glb` 已包含 `ConsoleActive`、`InnerDoorOpen/Close`、`OuterDoorOpen/Close` 和 `ThrusterBurn` 六个动画。
- 已读取实际 GLB，确认存在 `Anchor_CockpitCamera`、`Anchor_StandUp`、`Anchor_Console`、`Anchor_DoorInner`、`Anchor_Airlock`、`Anchor_EVA`、`Anchor_Tether` 等锚点。
- 门动画约 1.3 秒；运行时使用固定进度状态驱动动画采样，不依赖不可控的 wall clock。

### 架构边界

- 新增纯领域交互状态机，负责锚点选择、座椅/控制台状态、门进度、互锁、提示与暂停推进；不依赖 Three.js。
- 新增 Three.js 机械动画适配器，只负责把领域快照采样到既有 AnimationClip，并在销毁时释放 mixer。
- `ShipModelRuntime` 继续拥有 GLB、派生可见性、灯光和新 mixer；加载失败或锚点/动画缺失时进入稳定 fallback，并释放已经创建的资源。
- `ShipCameraPreview` 组合领域状态、相机模式和模型适配器；`SystemMapEngine` 只增加 `F` 键路由，不承载交互状态。
- 可见性使用门的真实进度，不改变 P3-T06 的内外裁剪原则。

### 必测矩阵

- 领域：两门互锁、反向中断、异常时间、暂停、控制台、座椅、保留锚点和复位。
- 资产：实际 PBR LOD1 的必需锚点和动画齐全，门动画采样改变节点变换，销毁幂等。
- 集成：按钮与 `F` 键走同一动作；视角切换同步座椅状态；暂停/失焦冻结；复位和退出清除状态；renderer 不重建。
- 门禁：`npm run typecheck`、`npm test`、`npm run build`、`git diff --check`、浏览器根页面实际交互。

### 回退与失败策略

- 不新增存档，刷新即恢复默认关闭状态。
- 模型或必需动画/锚点缺失时保持方向标记 fallback，禁用交互并提示返回全景重试。
- 任何加载中退出的迟到结果仍按 P3-T06 路径释放，不能重新挂载。

## C. Codex 实现与自查

- 新增纯领域状态机 `domain/shipInteraction.ts`：统一管理七个锚点、座椅、控制台、内外舱门进度、机械互锁、暂停推进和提示；无 Three.js 依赖。
- 新增 `rendering/spacecraft/shipMechanisms.ts`：校验并采样现有五个机械动画，在销毁时停止动作、解除根节点缓存并清空引用。
- `ShipModelRuntime` 读取真实 GLB 动画与七个锚点；缺失时失败关闭并释放模型；正常退出继续复用 P3-T06 的模型资源释放路径。
- `ShipCameraPreview` 和产品面板接入锚点选择、按钮及 `F` 键；驾驶座/站立点同步现有视角，复位恢复默认交互状态。
- 自动化结果（2026-09-20）：`npm run typecheck` 通过；`npm test` 为 159 passed / 0 failed；`npm run build` 通过；`git diff --check` 通过。
- 真实资产测试已解析 `spacecraft-pbr-lod1.glb`，确认七个锚点和必需动画存在，实际采样可改变内舱门节点变换；异常资产与迟到加载均进入稳定 fallback 并释放。
- 文件规模复核通过：本轮最大的渲染引擎 `systemMapEngine.ts` 为 376 行，其余新增/修改文件均低于对应上限。

## D. Codex 验收

结论：`accepted`。

- 根产品浏览器验收通过：正式 PBR LOD1 加载为“飞船已就绪”，桌面视口布局无横向裁切。
