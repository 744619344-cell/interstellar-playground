### 目标

- 为地球、月球、土星提供可选择的航线任务，并显示明确的航线阶段。
- 玩家从选择航线开始，经手动起航、巡航、接近，到达安全观测位置后完成航线。
- 航向辅助继续只修正朝向，不自动施加推进；玩家仍需驾驶。
- 航线跟随移动星体位置，暂停、隐藏、失焦和视角切换后状态稳定。

### 非目标

- 不制作或替换飞船、星体、驾驶舱、宇航员等模型或纹理。
- 不实现自动驾驶、跃迁、传送、存档、奖励、音频或新 URL 路由。
- 不改变太阳系尺度、轨道模型、固定时间步、碰撞保护半径或 Three.js 世界生命周期。
- 不安装依赖，不修改 Vite、TypeScript、包清单或锁文件。

### 影响范围

- 页面与组件：飞船导航面板中的三条标杆航线、阶段与完成提示。
- 领域模型与工具：纯函数航线状态机和到达判定。
- 渲染引擎：仅在现有飞船预览适配层接入航线状态，不修改太阳系渲染核心。
- 本地存储与备份：不涉及。
- 多端影响：仅桌面 Web。
- 权限与隐私：不涉及外部请求或用户数据。

### 验收标准

- [ ] 只提供地球、月球、土星三条航线，选择后锁定对应目标并开始任务。
- [ ] 航线至少具有 `未开始 / 巡航 / 接近 / 已抵达` 四个可观察状态；状态由纯领域逻辑计算。
- [ ] “已抵达”必须同时满足安全净空区间和低相对接近速度，不能以穿入保护体或高速掠过判定成功。
- [ ] 地球、月球、土星使用同一套通用判定；不得复制三份流程。
- [ ] 切换航线会清理上一条航线的完成状态并锁定新目标；清除目标或复位会取消当前航线。
- [ ] 暂停、页面隐藏/失焦和三种相机切换不会误推进航线状态，也不会重建 renderer。
- [ ] 航向辅助不施加推进，玩家输入优先级和防撞行为保持不变。
- [ ] UI 显示目标、当前阶段、距离/净空和下一步提示；完成后能选择另一条航线。
- [ ] 新增覆盖状态转换、到达边界、高速掠过、目标切换、暂停/视角切换的测试。
- [ ] `npm run typecheck`、`npm test`、`npm run build`、`git diff --check` 全部通过。

### 异常与边界场景

- 加载：航线状态不依赖异步外部资源。
- 空状态：未选择航线时保留现有“先选择目标”导航体验。
- 失败与回退：目标数据缺失或含非有限值时不完成航线，UI 回到可理解的等待状态。
- 取消：清除目标、复位、退出飞船预览均取消航线，不留下迟到更新。
- 旧数据：不涉及存档或迁移。
- 离线与跨设备：完全本地运行。
- WebGL 不可用或资源释放：沿用现有失败处理；不得新增 RAF、renderer 或未释放资源。
