### 目标

- 灰盒飞船根据前进、倒车、横移和制动显示程序化推进器光焰。
- HUD 以可读文字显示推进状态和姿态稳定状态。
- 使用 Web Audio 程序合成轻量基础推进声，不引入音频文件。
- 首次声音严格由用户操作解锁；暂停、失焦、隐藏、退出预览和销毁后静音或释放。

### 非目标

- 不制作 Blender 模型、复杂着色器、粒子系统或正式音效。
- 不建立 Phase 6 的四总线、音乐状态混合或音频许可扫描。
- 不修改飞行手感、碰撞、航线、太阳系尺度、存档或依赖。

### 验收标准

- [x] 前进、倒车和左右横移使用同一反馈模型产生方向正确的推进器视觉反馈。
- [x] 松开输入后的自动制动有短暂反馈，停止后回到待机；暂停/失焦时光焰立即隐藏。
- [x] HUD 显示推进状态及“姿态稳定/姿态调整中”，不只显示原始四元数。
- [x] 声音仅在用户点击进入或操作飞船后创建/恢复 AudioContext；页面加载不自动播放。
- [x] 声音强度随推进反馈变化，暂停、失焦、页面隐藏、退出预览时归零；恢复页面不自动大声播放。
- [x] destroy 停止并断开音频节点、关闭 AudioContext；重复销毁安全。
- [x] 不新增外部资源、依赖、额外 RAF 或 renderer。
- [x] 自动化覆盖反馈纯逻辑、音频解锁/暂停/恢复/销毁和现有渲染生命周期。
- [x] 类型检查、完整测试、生产构建及桌面浏览器验收通过。
