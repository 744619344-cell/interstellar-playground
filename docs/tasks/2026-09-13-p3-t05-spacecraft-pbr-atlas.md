# P3-T05：PBR 材质烘焙、纹理图集与 GLB 优化

## A. 规格

- 状态：`accepted`（资产优化级）；等级/路线：C2，Codex 主导，沿用已确认的 GPT-6 专业制作授权。
- 用户确认 P3-T04 后继续下一项。保留已确认的形状、配色、机械动画、尺寸及锚点。

- 原始材质为常量 PBR，无高模纹理细节可转移。本轮将常量材质解析烘焙为基础色、ORM 与自发光图集；不虚构 AO 或高低模法线烘焙。AO 中性白，保留已有几何与法线细节。
- 基础色、自发光用 sRGB，ORM 线性且 R=1、G=粗糙度、B=金属度；导出 WebP，不新增外部贴图或依赖。

## B. 前置评审

- 内外部分别使用材质色块图集，纯色零件 UV 位于各自色块内部；这保留原常量外观，不假装为可绘制局部磨损的独立 UV 展开。
- 按静态模块合并同一父节点下的网格，保留船壳、左右推进舱、家具、顶板、墙壁边界，为 P3-T06 裁剪保留边界。门扇、控制条、喷焰、锚点不参与静态合并。
- 机械片段、锚点和几何面数必须与 P3-T04 对齐。独立源读取已验收机制工程，不覆盖前序源或 GLB。
- 两套三张 2K RGBA 图集含 mip 约 128 MiB；两档应共享纹理，独立查看器需去重。两档 GLB 总大小目标不超过 8 MiB；不将图集合并宣称为几何减面。
- 允许：本任务、README、路线图、P3-T04 确认记录及登记、新 PBR 资产登记；新 `assets-source/blender/spacecraft/pbr/`；相关新增脚本；共用 GLB 校验/修正、机械回归测试及查看器必要兼容；`src/assets/models/spacecraft-pbr-lod{0,1}.glb`。
- 禁止：覆盖已验收源与 GLB、改变动画/轴向/几何形状、产品 renderer/业务/飞行/音频、依赖和外部资产、提交/推送/部署。远景静态 LOD2 保留；正式运行时分包仍属后续任务。
- 回退：当前产品未引用派生资产；旧资产和查看器保持可用。

## C. 实现

- 常量 PBR 解析烘焙脚本 `bake_pbr_atlas.py` 从已验收 GLB 读取材质，生成内外部各 Base / ORM / Emission 三张 2048² 无损 WebP；原始 15 种常量材质写入色块图集，喷焰材质保留独立。
- `pbr_materials.py` / `build_pbr.py` 为网格分配色块 UV，按船壳、左右推进舱、家具、顶板、后框合并；原本 45 网格 / 16 材质降为 24 / 3。墙壁、顶板、船壳及机械节点仍可独立控制。
- 两档面数保持 237312 / 123408，不减面、不改变机械片段。`finalize_glbs.mjs --pbr` 修正 Meshopt 边界和静止姿态，内嵌原始无损 WebP，补齐中性 AO 引用。
- 新图集查看器共用机械控制逻辑；两档按图集名及颜色空间共享六张纹理。纹理、ImageBitmap、模型、mixer、环境、renderer 退出释放，最终销毁 WebGL 上下文；加载中退出会丢弃并释放迟到模型。
- 实测 GLB 为 2464244 / 1437104 字节，共约 3.72 MiB，比原机制两档合计增加 52176 字节（约 1.36%），换取完整装配视角 draw calls 从 45 到 24（降低约 46.7%）。没有宣称文件变小或 GPU 纹理内存下降。
- 交付和复现见 [PBR 资产登记](../space-exploration/13-SPACECRAFT-PBR-ASSETS.md)。所有报告位于 `assets-source/blender/spacecraft/pbr/`。
