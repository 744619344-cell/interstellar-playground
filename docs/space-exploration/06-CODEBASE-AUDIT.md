# 当前代码盘点

本文件描述独立桌面 Web 项目的代码边界，不再盘点旧仓库的多端入口。进度细节以 [04-DELIVERY-ROADMAP.md](04-DELIVERY-ROADMAP.md) 为准。

## 当前保留

- 根地址直接进入 `SystemMapShell`（`src/App.tsx`），无 feature flag
- 单画布太阳系全景、星体聚焦、暂停、本地音乐（浏览器 IndexedDB，不进仓库）
- 飞船相机试验、直控移动、目标导航、防撞、地球/月球/土星航线
- 程序化推进光焰与用户手势解锁的基础推进声
- 星体 LOD2/LOD1 切换与迟到纹理取消
- 运行时依赖仅 React、React DOM 与 Three.js

- 微信小程序、Taro 配置和移动端适配
- 太阳系浮动原点与超阈值重定位（飞船预览局部偏移不是该能力）
- 星体 LOD0 近景、正式飞船/宇航员 GLB、舱内与 EVA
- 运行时资源预算检查、性能采样面板、20 分钟内存脚本
- 四总线音频与《星际穿越》原声
