# 《我们的宇宙：太阳系远征》产品需求文档

> 文档状态：开发前基线
> 产品代号：Solar Expedition
> 目标版本：V1.0 垂直切片至 V2.0 完整体验

## 1. 产品定义

把当前“太阳系总览 + 各天体独立页面”升级为一个持续存在的太阳系探索世界。玩家在同一个画布中观察整个太阳系、驾驶飞船接近任意星体、进入飞船内部，并控制宇航员完成气闸和舱外活动。

一句话体验：**从完整太阳系中选择目标，亲自驾驶一艘有真实内舱和宇航员的探索飞船，连续飞向星体并完成安全的舱外观测。**

## 2. 产品目标

### 2.1 必须实现

1. 太阳、八大行星和月球同时存在于一个 WebGL 场景，不通过页面切换销毁世界。
2. 玩家可从太阳系全景连续缩放到单颗星体近景，星体细节随距离渐进提升。
3. 飞船支持第三人称、驾驶舱和自由观察视角。
4. 玩家可控制飞船推进、制动、偏航、俯仰、滚转和姿态稳定。
5. 飞船拥有可进入的驾驶舱、生活舱与气闸舱。
6. 宇航员支持坐姿、起身、舱内移动、进入气闸、出舱、舱外移动和返回。
7. 舱外活动必须经过头盔、生命维持、安全绳和气闸互锁检查。
8. 目标、风险、航向和下一步操作始终清晰，不依赖长说明才能游玩。
9. 桌面端保持稳定流畅；移动 Web 提供明确降级，不承诺完整内舱与舱外体验。
10. 背景音乐支持授权音乐或原创替代曲，并具备静音、音量和场景淡入淡出。

### 2.2 不在首版范围

- 微信小程序版本。
- 真实比例的行星距离和实时轨道计算。
- 多人联机、战斗、制造、生存和资源经济系统。
- 十颗星体同时拥有可登陆地表。
- 飞船自由改装和复杂驾驶仪表模拟。
- 旧小游戏成绩迁移。
- 未授权商业音乐随产品发布。

## 3. 核心体验闭环

```text
观察太阳系 → 选择目的地 → 进入驾驶位 → 起航
→ 巡航与导航 → 接近星体 → 进入观测位置
→ 可选舱外活动 → 记录成果 → 返回飞船 → 选择下一目标
```

## 4. 单画布太阳系

### 4.1 全景模式

- 首屏展示完整太阳系和玩家飞船位置。
- 滚轮、触控板或双指用于缩放；拖动用于环绕观察。
- 点击星体显示名称、视觉距离、探索状态和“设为目标”。
- 星体轨道用于帮助理解结构，不宣称真实比例。
- 可随时从局部视图平滑返回全景，不重置飞船和任务状态。

### 4.2 星体聚焦

- 双击或点击聚焦按钮后，摄像机平滑靠近目标。
- 星体从远景代理模型切换到中景和近景资源。
- 过渡期间不出现黑帧、纹理闪烁、穿模或明显跳变。
- 近景至少能够看清主要纹理、大气、云层或星环特征。

### 4.3 视觉尺度

- 使用观赏尺度压缩天体距离和尺寸差异。
- HUD 明确标注“视觉比例，非真实等比例”。
- 航行距离和时间是游戏化单位，不伪装成精确天文模拟。
- 接近星体后切换局部坐标系，保证飞船和宇航员尺度稳定。

## 5. 飞船玩法

### 5.1 控制

| 操作 | 键位 | 行为 |
| --- | --- | --- |
| 主推进 | W | 沿飞船前向持续加速 |
| 制动/反推 | S | 降低当前速度 |
| 偏航 | A / D | 左右调整航向 |
| 俯仰 | 鼠标纵向或方向键 | 抬头/低头 |
| 滚转 | Q / E | 绕前向轴旋转 |
| 脉冲推进 | Shift | 短时加速，有冷却时间 |
| 姿态稳定 | Space | 自动减小旋转与侧向漂移 |
| 视角切换 | C | 驾驶舱、第三人称、自由观察 |
| 交互 | F | 座椅、舱门、控制台、气闸交互 |

控制采用易上手的惯性飞行。系统可以提供航向辅助和近星体防撞保护，但不替玩家自动完成全部航程。

### 5.2 飞船功能区

- 驾驶舱：驾驶、导航、目标锁定和视角切换。
- 生活舱：宇航员移动与过渡空间。
- 气闸舱：装备检查、减压、舱门互锁与出舱入口。
- 外部锚点：安全绳连接和返回定位。
- 推进系统：主推进器、姿态推进器、光效和内部反馈音。

### 5.3 相机

- 第三人称相机跟随飞船并允许有限环绕。
- 驾驶舱相机固定在座椅视点，保留适量仪表和舷窗视野。
- 自由观察用于查看飞船整体，不改变飞船方向。
- 视角切换时保持航行状态，避免瞬移和方向反转。

## 6. 宇航员与舱外活动

### 6.1 角色状态

```text
Seated → StandUp → CabinWalk → AirlockReady
→ Depressurizing → EVAExit → EVAMove
→ EVAReturn → Pressurizing → CabinWalk → Seated
```

### 6.2 舱内移动

- 飞船处于稳定航行或自动驾驶状态时才允许离开驾驶位。
- 舱内采用第三人称近距离相机，必要时自动避障。
- 角色脚底必须贴合舱面，不允许滑步、陷地和动作失效。
- 背包、手指和软管不得因动画权重错误发生明显扭曲。

### 6.3 保护装置

出舱前必须满足：

1. 宇航服密封完成。
2. 头盔锁定。
3. 氧气与电量高于安全阈值。
4. 生命维持背包在线。
5. 安全绳连接飞船锚点。
6. 内舱门关闭。
7. 气闸完成减压。

任一条件未满足时，外舱门保持锁定并显示具体原因。

### 6.4 舱外控制

- WASD 控制平面推进，Q/E 控制升降或滚转。
- 鼠标改变观察与推进朝向。
- 安全绳限制最大距离并提供回收功能。
- 失去控制时提供一次自动姿态稳定，不设计永久漂失惩罚。

## 7. 星体细节与首版目标

首个质量标杆采用地球、月球和土星：

- 地球：昼夜、云层、城市灯光、大气和近轨观测。
- 月球：真实纹理、环形山层次、地球升起视角和舱外活动验证。
- 土星：高质量星环、卡西尼缝、环影和飞船掠过。

其余星体首版需要在同一太阳系中可见、可聚焦、可导航接近，但只提供基础观测。

## 8. 音频需求

### 8.1 音乐

- 支持巡航、接近、危险和舱外四种音乐状态的平滑混合。
- 用户提出的《星际穿越》原声只有在获得作品与录音授权后才可进入发布包。
- 开发期可以通过本机路径加载授权测试音源，但文件不得提交仓库、不得进入构建产物。
- 无授权时使用原创音乐：管风琴音色、低频持续音、稀疏脉冲和渐进张力；不得复制原曲旋律、和声编排或可识别片段。

### 8.2 声音

- 太空外部不直接传播声音；推进、碰撞和舱门声音通过飞船结构反馈表达。
- 舱内外必须有明显声场差异。
- 音乐、环境、UI 和语音提示分别调节音量。
- 页面隐藏时暂停音频，重新获得焦点时不得未经用户交互自动大声播放。

## 9. HUD 与引导

长期显示不超过五类信息：目标、距离、速度、姿态/航向和当前安全状态。任务提示按情境出现：

- 航向偏离时指出修正方向。
- 接近速度过高时提前给出制动距离。
- 离开驾驶位前提醒开启自动驾驶。
- 气闸流程逐项展示检查状态。
- 舱外氧气、电量和安全绳状态始终可见。

## 10. 数据与存档

- 保存设置、当前目标、飞船位置、当前视角、探索成果和授权音频偏好。
- 新玩法使用独立版本化存储键。
- 不迁移旧小游戏成绩；旧数据可以保留但不参与新主循环。
- 私人照片继续只保存在本机，不上传服务器。
- 存档损坏时回退到安全出生点，不阻止应用启动。

## 11. 首版完成定义

- 单画布内同时看到太阳、八大行星、月球和飞船。
- 全景、聚焦、近景之间连续切换。
- 飞船可完整飞向地球、月球和土星。
- 驾驶舱与第三人称视角可切换。
- 宇航员能从座位移动到气闸，并完成一次有安全检查的月球轨道舱外活动。
- 星体、飞船、宇航员和音频通过性能与版权门禁。
- Chrome 和 Edge 桌面端满足测试基线，移动端提供降级或设备能力提示。
