# 决策、风险与版权清单

## 1. 已确定的产品决策

| 项目 | 决策 |
| --- | --- |
| 平台 | 仅桌面 Web；不做微信小程序，不做移动端适配或降级 |
| 世界 | 所有主要星体存在于同一画布 |
| 比例 | 观赏尺度，不使用真实天文比例直接渲染 |
| 飞船 | 可驾驶，支持外部、驾驶舱和自由观察视角；正式概念已确认 15.6 × 7.8 × 4.8 m、暖白/石墨/青色工业风 |
| 内舱 | 驾驶舱、生活舱、气闸舱 |
| 宇航员 | 支持舱内移动、气闸和 EVA |
| 安全 | 头盔、生命维持、安全绳、压力和双门互锁 |
| 建模 | Blender 模块化制作，先灰盒后正式资产 |
| 历史数据 | 不迁移旧小游戏成绩 |
| 音乐 | 支持《星际穿越》授权版或原创合法替代曲 |

## 2. 开发前仍需用户确认

这些选择不阻塞太阳系灰盒，但在对应美术或音频阶段前必须确认：

1. ~~飞船风格。~~ 已确认：NASA 近未来 + 简洁现代工业风（P3-T01，2026-09-12）。
2. ~~飞船规模。~~ 已确认：15.6 × 7.8 × 4.8 m 双人单层（P3-T01）。
3. ~~主视角优先级。~~ 已确认：第三人称识别轮廓，驾驶舱保证前向视野，二者同为建模门禁（P3-T01）。
4. 宇航员是否沿用当前概念插图外观，还是重新选择更适合动画的资产。
5. EVA 首发地点：建议月球近轨或月面上空。
6. 音乐路径：采购《星际穿越》授权，或委托原创替代曲。

移动 Web 观察/简化飞行不再作为待选项：唯一目标平台是桌面 Web。

## 3. 主要技术风险

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| 天文尺度与米级内舱混用 | 抖动、裁剪、穿模 | 三层坐标、浮动原点、动态裁剪面 |
| 所有星体高精度常驻 | 显存过高、掉帧 | LOD、资源流送、引用计数和预算驱逐 |
| 飞船内外同时渲染 | draw call 与纹理爆炸 | 视角可见集、舱室裁剪、独立 LOD |
| 自动绑定动画不稳定 | 手指、背包、脚底异常 | Blender 权重返修、硬表面附件、三视角验收 |
| 模式切换产生重复循环 | CPU/GPU 泄漏 | 单 runtime、组合暂停、生命周期压力测试 |
| 异步纹理迟到 | 已卸载场景被写入 | AbortController、generation 校验 |
| 音频自动播放限制 | 无声或报错 | 用户手势解锁、显式播放状态 |
| 商业音乐无授权 | 无法发布、侵权 | 构建许可门禁、原创替代曲 |

## 4. 产品风险

- 范围过大：用地球、月球、土星和一艘灰盒飞船限制首个垂直切片。
- 美术投入过早：灰盒操控、尺度和镜头未确认前，不制作最终内舱。
- 操作复杂：默认启用姿态辅助，逐步解锁滚转和 EVA 操作。
- 信息过载：每个模式只显示当前必要的五类信息。
- 太阳系航程空洞：使用短航线、目标锁定和少量真实现象事件，不靠长时间等待制造尺度感。

## 5. 版权和资产许可

每个外部资源必须记录：

- 文件 ID 与仓库路径
- 资源名称和作者
- 原始下载地址
- 许可证全文或链接
- 商用、修改、再分发和署名要求
- 下载日期
- 本项目修改内容
- 是否允许进入生产构建

缺少任一关键许可信息的资产只能作为本机参考，不能提交或发布。

## 6. 《星际穿越》音乐要求

《星际穿越》电影配乐及其商业录音通常同时涉及音乐作品权和录音制品权。购买个人播放服务或电影并不等于获得网站公开传播和同步使用授权。

发布前必须拥有能够覆盖以下用途的书面授权：

- 在互动 Web 产品中与画面同步使用。
- 通过互联网向公众传播。
- 在目标地区和期限内使用。
- 使用指定录音版本，而不仅是曲谱作品。
- 允许必要的剪辑、循环、淡入淡出和动态混音。

如果授权未完成：

- 仓库和构建产物不得包含原声文件或可识别片段。
- 开发者可在本机以未纳入版本控制的配置加载合法持有的测试文件。
- 正式版本使用原创宇宙氛围音乐，不复制原曲旋律、主题或可识别编排。

建议在 `.gitignore` 中为本地测试音源预留目录，并由构建脚本校验生产清单；具体实现放到 Phase 6。

## 7. 安全与隐私

- 本机文件路径不得写入代码、日志、存档或仓库。
- 私人照片不得作为纹理上传外部服务。
- Blender 源文件在包含嵌入图像时需要检查个人信息。
- 日志不记录完整存档、用户照片名称或授权文件内容。
- 外部模型进入 Blender 前进行文件来源检查，并仅通过可信工具链转换。
