# 测试、验收与发布基线

唯一目标平台是桌面 Web。不为移动端或微信小程序做功能、视口或性能验收。

## 1. 每个任务的最低检查

```bash
npm run typecheck
npm test
npm run build
git diff --check
git status --short
```

不得以历史测试结果代替本轮结果。自动化通过不能代替视觉和行为验收。

## 2. 功能验收

### 2.1 单画布

- 太阳、八大行星和月球同时存在。
- 全景、聚焦、航行和近景切换不重建整个渲染器。
- 独立星体 URL 刷新后进入统一世界并聚焦目标。
- 浏览器前进、后退不会丢失世界状态或出现重复 RAF。

### 2.2 飞船

- 六方向输入和姿态稳定方向正确。
- 不同帧率下加速度、最大速度和制动距离一致。
- 视角切换不改变速度和航向。
- 接近星体时不会穿模、抖动或被弹飞。
- 失焦、暂停和弹窗期间停止输入与模拟。

### 2.3 宇航员

- 座椅、起身、行走、转身、气闸、EVA 和返回状态可完整往返。
- 行走时脚底稳定，无抱胸、滑步、陷地、手指折叠和背包扭曲。
- 动作缺失或加载失败时进入稳定待机，不继续代码位移造成滑行。
- 相机可环绕查看角色整体，不影响角色朝向。

### 2.4 气闸

- 内外门互锁。
- 未密封头盔、未连接安全绳、压力不正确时拒绝出舱。
- 每次拒绝都显示明确原因。
- 页面隐藏、刷新或崩溃恢复后处于安全状态。

### 2.5 音频

- 首次播放遵守浏览器用户手势要求。
- 音乐状态切换无爆音、重叠累积和明显断点。
- 静音与音量立即生效并持久化。
- 页面隐藏停止音频；恢复时遵守用户设置。
- 构建产物不包含未授权音乐或开发期本机测试音源。

## 3. 视觉矩阵

最低桌面视口：

- 1366×768
- 1920×1080
- 2560×1440

不为移动端视口做降级验收。每个视口检查：全景、星体聚焦、第三人称飞船、驾驶舱、舱内、气闸、EVA、帮助和设置。

视觉失败条件：

- HUD 超出视口或遮挡主要目标。
- 页面出现滚动条或白色尾部。
- LOD 跳变、纹理白闪、Z-fighting、影子漂浮。
- 星体占画面 50% 时明显像素化。
- 飞船内外穿透，舱门与碰撞状态不一致。
- 宇航员身体、手指、背包出现明显非自然形变。

## 4. 性能门禁

### 4.1 测试场景

1. 全太阳系全景持续运行 5 分钟。
2. 连续聚焦地球、月球、土星各 10 次。
3. 飞船连续航行 10 分钟并切换三种相机。
4. 舱内和 EVA 各连续运行 5 分钟。
5. 页面隐藏/显示、帮助弹窗和画质切换各 20 次。

### 4.2 通过标准

- 桌面标准配置平均 ≥ 55 FPS，1% low ≥ 35 FPS。
- 桌面节能平均 ≥ 28 FPS。不验收移动降级 FPS。
- 单次常规交互主线程长任务不超过 100 ms。
- 连续 20 分钟后 JS Heap 增长趋于稳定，不持续线性上涨。
- 场景切换后旧纹理、材质、几何、动画和音频节点可回收。
- 首次可交互 ≤ 4 秒；高精度资源允许渐进加载。

## 5. 浏览器与设备

- Chrome 当前两个主版本。
- Edge 当前两个主版本。
- Safari 当前两个主版本（桌面），至少完成基础观察检查。
- WebGL2 不可用时显示可理解的降级说明。
- `prefers-reduced-motion` 下关闭不必要震动、强烈视差和高强度转场。

## 6. 自动化测试层级

- 领域测试：航行、坐标转换、LOD、气闸、安全绳、存档。
- 生命周期测试：重复 start/pause/resume/destroy、迟到加载和上下文丢失。
- 组件测试：HUD、导航、气闸清单、设置和错误回退。
- 浏览器测试：路由刷新、输入、视角、弹窗、音频解锁和控制台错误。
- 资产测试：GLB 大小、骨骼、动作名、纹理槽、三角面和许可证字段。

## 7. 发布前检查

- 生产构建成功且无意外大资源进入首包。
- 资源清单中的每个文件都有来源和许可证。
- 《星际穿越》或其他商业音乐没有授权文件时，构建必须使用原创/占位音轨。
- Source map、日志和错误信息不包含本机路径、个人照片和秘密信息。
- 私人照片仍只在本机存储。
- 新存档损坏不会阻断启动。
- 所有失败页面有重试和返回路径。

## 8. 验收结论

每个阶段结论只能为：

- 通过
- 有条件通过
- 修改后复验
- 不通过

阻断问题必须列出最小返修范围，不在验收阶段顺带扩大产品范围。
